# Public Mesa · Contribute with GitHub preceptors

**Purpose:** Public missions for people and AI preceptors who build **by, for, or with** PreceptorOS.
**State:** PROPOSED · 2026-11-10. The catalog and contributor guide are in [draft PR #2](https://github.com/piskyRpapalo/preceptoros-public-mesa/pull/2), not yet in `main`.

## What you can do

- **By the community:** Check links, tests, access needs, or public docs.
- **For the community:** Add a small tool or a test with a clear source and result.
- **With the community:** Propose one public mission and review one draft PR.

Start with [the three starter missions (draft)](https://github.com/piskyRpapalo/preceptoros-public-mesa/pull/1). The [29-mission catalog (draft)](https://github.com/piskyRpapalo/preceptoros-public-mesa/pull/2) is not an active task board until review.

## Read, write, and verify

1. Read the mission and the owner repository's `AGENTS.md`.
2. Check [Study](https://github.com/piskyRpapalo/study), the [Renaming Law](https://github.com/piskyRpapalo/study/blob/main/10-collisions.md), and the [Rosetta](https://github.com/piskyRpapalo/study/blob/main/13-rosetta.md).
3. Apply the **Renaming Law**: use the official English term. Keep earlier names as dated aliases. Do not rewrite past evidence.
4. Apply the **Rosetta**: translate Spanish source terms to the official term. Do not create a new term. [Babel](https://github.com/piskyRpapalo/babel/blob/main/registry/reading-directions.md) is the vocabulary home.
5. Search for an existing mission or tool before you propose a new one. The [WEB map §9](https://github.com/piskyRpapalo/preceptoros-web/blob/main/docs/canon-map-details-20261107.md) is still the single mission source.
6. Use a GitHub Issue for an idea or a reproducible problem. Use a draft Pull Request for a change. Name the files and attach test steps.
7. Mark each result `MEASURED`, `PROPOSED`, or `NO_DATA` with its cause. State the SHA and source. Do not call a fixture a live result.
8. Ask for human review. The Sovereign signs an exact PR head. An agent must not sign or merge for the human.

## The two Mesas

**Public Mesa:** reviewed, scrubbed missions and work that anyone can read. No private access is needed.

**[Private Mesa](https://github.com/piskyRpapalo/preceptoros-private-mesa):** internal preceptor coordination, private evidence, collisions, and sign-off review. Public contributors do not need access to it.

These are two RAG/harness **reading and writing surfaces**, not proof that an automatic sync is running. `NO_DATA: cross_mesa_sync_not_measured`.

## Rules for publication

Use public sources. Do not paste secrets, private paths, rack addresses, or private comments. Keep sentences short. Use one term for one meaning. Give an exact test and a reason for every missing measure.
