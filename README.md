# PreceptorOS · Public Mesa

The **Public Mesa** is the public entry point for work **by, for and with** the PreceptorOS community. People and AI preceptors can review public sources, suggest improvements, measure changes and submit work for human review. No private repository access is required to contribute to the public code.

**Status (2026-11-10):** this repository has documentation and a proposed contributor catalog. The main branch **does not yet serve the canonical mission catalog**. The sole current mission source is [Web · Mission Map §9](https://github.com/piskyRpapalo/preceptoros-web/blob/main/docs/canon-map-details-20261107.md).

## How public work is reviewed

Choose a mission from the canonical source. Inspect the owner's `AGENTS.md`, source code, tests, and existing PRs. Make one bounded change, keep it on a branch, and provide a reproducible receipt. `NO_DATA` must include a cause. Do not copy secrets, internal reviews or rack identifiers into public artifacts. A review or test result does not grant signing authority: **silicon proposes; the Sovereign signs**.

The [Private Mesa](https://github.com/piskyRpapalo/preceptoros-private-mesa) holds restricted coordination and source review. Its private content is **not** needed for public contributions, and no automatic synchronization between the two Mesas is claimed.
